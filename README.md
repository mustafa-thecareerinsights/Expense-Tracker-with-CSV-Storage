# Expense Tracker with CSV Storage

## Project Title
Expense Tracker with CSV Storage

## Objective
The objective of this project is to develop an expense management application using Python. The application stores expense records permanently in a CSV file.

## Features
- Add and save expenses to a CSV file
- View all expenses
- Filter expenses by date
- Filter expenses by month
- Calculate total expenses
- Generate expense summary report
- Proper exception handling
- Input validation

## Fields
The project uses the following fields:

1. Expense ID
2. Title
3. Amount
4. Date
5. Category

## Files
- expense_tracker.py
- expenses.csv
- README.md

1. Open the project folder.
